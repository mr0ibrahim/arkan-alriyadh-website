# حزمة الجودة قبل نشر أركان الرياض

## التركيب
1. احفظ العمل في Git، وأنشئ فرعًا منفصلًا.
2. انسخ محتويات هذه الحزمة إلى جذر المشروع واستبدل الملفات المتطابقة.
3. لا تحذف node_modules أو package.json أو .git.
4. نفّذ `npm run build` ثم `node scripts/check-build.mjs` ثم `npm run dev`.
5. افحص بصريًا الصفحة الرئيسية والخدمات الخمس على هاتف وكمبيوتر؛ جرّب معرض الصور والروابط.
6. بعد نجاح الاختبار: `git add .` ثم `git commit -m "feat: prelaunch quality checks and editable business settings"`.

## تعديل الاسم والشعار والصور
- بيانات النشاط ورقم الهاتف: `src/data/site.ts`.
- صور الخدمات والمعرض: `src/data/gallery.ts`، وضع الصور في `public/images/`.
- شعار النشاط في `src/components/Header.astro` و`public/favicon.svg` عند اعتماد التصميم النهائي؛ حاليًا لا يوجد شعار تجاري مرخص نهائي.
- تحقق من الترخيص لكل صورة ولا تنسب صور الإلهام لأعمال منفذة.

## منع الفهرسة قبل النشر
الموقع التجريبي يبقى `noindex` و robots.txt Disallow، حتى لو وُضع دومين تجريبي. لا تفعّل `PUBLIC_ALLOW_INDEXING=true` إلا بعد شراء دومين نهائي، واعتماد الاسم والشعار وسياسة الصور؛ عندها ضع `PUBLIC_SITE_URL=https://your-real-domain.sa` قبل عملية البناء، وأعد البناء.

## قبل إطلاق الإنتاج
- اختبر الإعدادين: `PUBLIC_SITE_URL` و`PUBLIC_ALLOW_INDEXING=true` مع `npm run build`؛ ثم `set EXPECT_PRODUCTION=1 && node scripts/check-build.mjs` في CMD (فقط للإنتاج).
- تأكد من canonical و Open Graph و sitemap و HTTPS بعد النشر.
- اختبر رقم الواتساب والاتصال من هاتف فعلي، وفحص Lighthouse ومقاسات الشاشات.
- تحقق من العلامة التجارية وتراخيص الصور، مع استبدال الرسومات التوضيحية بصور محترفة.
- لا تضع معلومات سرية داخل PUBLIC_* لأنها تظهر للعامة.

## ملاحظات
- اختبار الروابط محلي فقط، ولا يثبت صلاحية روابط الصور الخارجية أو جودة الأداء الفعلية.
- الأخطاء في الصور الخارجية لا تمنع البناء، لذلك يفضّل استضافتها محليًا بإذن وترخيص.
- المحتوى الحالي اسم مؤقت وغير جاهز للترويج قبل المراجعة القانونية والتجارية.
