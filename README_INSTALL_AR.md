# أركان الرياض — حزمة الإكمال التقني

## الدمج الآمن مع مشروعك الحالي

1. المشروع الحالي على Git عند `2d32c6d` بنسخة سليمة؛ تأكد من `git status --short` وعدم وجود تعديلات معلقة.
2. أنشئ نسخة احتياطية أو فرعًا: `git switch -c feature/finish-website`.
3. فك الضغط داخل مجلد المشروع `C:\dev\projects\arkan-alriyadh-website` واسمح بدمج مجلدات `src` و`public` واستبدال ملفاتها الموجودة. لا تحذف `package.json` أو `node_modules`.
4. شغّل `npm run build` ثم `npm run dev`، وجرّب الرئيسية وخمس صفحات خدمات ومعرض الصور والاتصال والواتساب.
5. قبل الالتزام بالتغييرات: `npx astro check` (إذا طلب تثبيت @astrojs/check وtypescript ثبّتهما عبر `npx astro add check` ثم أعد الفحص).
6. إن نجح الاختبار: `git add .` ثم `git commit -m "feat: complete service pages SEO and contacts"`.

## روابط الاختبار
- `/` الرئيسية
- `/services/sheeboard/`
- `/services/parquet/`
- `/services/fiber-skirting/`
- `/services/foam-mouldings/`
- `/services/painting/`
- `/404` الصفحة غير الموجودة
- `/robots.txt` و`/sitemap.xml` — متعمد ألا يفهرسا نسخة بلا دومين.

## قبل الإطلاق النهائي — مطلوب منك
1. التحقق من الاسم والشعار رسميًا؛ الاسم الحالي غير مسجل بحسب إفادتك.
2. اعتماد الصور التجارية واستبدال الروابط الخارجية بصور محلية مرخصة.
3. شراء الدومين والاستضافة وضبط متغير البيئة `PUBLIC_SITE_URL` في بيئة البناء على القيمة الحقيقية مثل `https://example.sa` (لا تستخدم المثال نفسه).
4. إعادة تشغيل `npm run build` والتأكد من `robots.txt` و`sitemap.xml` وعنوان Canonical والبيانات المنظمة.
5. نشر المشروع عبر GitHub/Cloudflare Pages: أمر البناء `npm run build`، والمجلد الناتج `dist`.
6. اختبار الموقع على هاتف حقيقي، سرعة الصفحات، الوصولية، وروابط الهاتف والواتساب؛ ثم إعداد Google Search Console وتقديم خريطة الموقع.

## استبدال الصور
- ضع الصورة في `public/images/` مثل `parquet.webp`.
- افتح `src/data/gallery.ts` وحدّث `src` للصورة إلى `/images/parquet.webp`.
- تتحدث صورة البطاقة وصورة الخدمة والمعرض بالاعتماد على هذا الملف.
- إذا أضفت صورًا أخرى أضف عناصر جديدة إلى قائمة `gallery` بنفس البنية.

## تنبيه مهم
هذه **حزمة ملفات مصدر مكملة** وليست نشرًا مكتملًا. لا يمكن اختبار الدمج مع جهازك أو تقرير جاهزية النشر قبل تشغيل الاختبارات لديك. الصور الحالية مرجعية وليست أعمالًا مثبتة التنفيذ.
