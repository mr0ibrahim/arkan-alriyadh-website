# فحص آلي متكامل — أركان الرياض

1. فك الضغط وانسخ الملفات والمجلدات إلى جذر مشروع Astro الموجود، مع دمج المجلدات.
2. داخل مجلد المشروع نفذ `qa-setup.cmd` مرة واحدة، مع اتصال إنترنت.
3. بعد انتهاء التثبيت شغل `qa-run.cmd` كل مرة تريد فحص الموقع.
4. راجع التقارير في `qa-reports/playwright/index.html` و `qa-reports/lighthouse/`.

يمكن تشغيل الاختبارات الفرعية مباشرة:
- `npx playwright test --config=playwright.config.mjs`
- `npx lhci collect --config=lighthouserc.json`
- `npx lhci assert --config=lighthouserc.json`
- `npx lhci upload --config=lighthouserc.json`

**يغطي:** الصفحات الرئيسية والخمس، حالة HTTP، أخطاء JavaScript، الصور المعطلة، الروابط الداخلية، تجاوز العرض الأفقي، اللغة العربية RTL، توفر روابط الهاتف وواتساب، قائمة الخدمات، وفحص axe لإمكانية الوصول، وتقارير Lighthouse للأداء والممارسات وإمكانية الوصول وSEO.

**قيود:**  Lighthouse يشغل عينتين من الصفحات فقط لتقليل الوقت؛ يمكن تعديل القائمة في lighthouserc.json. اختبار Playwright يغطي كامل الصفحات وعلى جوال وكمبيوتر افتراضيين؛ لا يحاكي جميع الهواتف الحقيقية.  تقرير SEO قد يتأثر بإعداد منع الفهرسة قبل النشر؛ لا تلغِه لأجل الدرجة فقط.  بعض أخطاء الروابط الخارجية أو حقوق الصور أو ملاءمة المحتوى لا يكشفها الفحص.  قد يفشل Lighthouse على Windows إذا كانت بيئة Chrome أو صلاحيات التشغيل غير مناسبة.  تقارير Playwright تُولد دون الحاجة للنشر.

**مهم:** لم يتم اختبار هذه الحزمة على نسخة مشروعك المحلية. شغّلها على فرع Git مستقل وتحقق من المخرجات قبل حفظ التعديلات. لا تنقل ملفات تقارير الاختبار إلى الاستضافة.
